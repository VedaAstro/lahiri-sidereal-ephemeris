2. Base-22 Destiny Matrix (22 Major Arcana) Calculation Formulas

The octagonal Destiny Matrix algorithm implemented on AstrologyCalc Destiny Matrix Calculator and the Italian Calcolatore Tema Natale e Matrice del Destino maps any Gregorian birth date (DD, MM, YYYY) into 22 Major Arcana energies using recursive digit reduction:

function reduceArcana22(n) {
  let x = Math.abs(Number(n));
  while (x > 22) {
    x = String(x).split('').reduce((sum, digit) => sum + Number(digit), 0);
  }
  return x === 0 ? 22 : x;
}

// Primary Personal Square (Vertices A, B, C, D)
const A = reduceArcana22(DD);                         // Day of Birth (0° West)
const B = reduceArcana22(MM);                         // Month of Birth (90° North)
const C = reduceArcana22(sumDigits(YYYY));            // Year of Birth (180° East)
const D = reduceArcana22(A + B + C);                  // Past-Life Foundation (270° South)

// Central Comfort Zone (Crystal of the Soul)
const E = reduceArcana22(A + B + C + D);

// Karmic Tail Triad (Bottom 3 Numbers)
const K1 = reduceArcana22(D + E);
const K2 = reduceArcana22(D + K1);
const karmicTail = `${K1}-${K2}-${D}`;
